## Configuration files location

All UmmItOS configuration files live in:

- **Main config**: `~/.config/` (all application configs)
- **Hyprland**: `~/.config/hypr/hyprland.lua` plus the `~/.config/hypr/hyprland/*.lua` modules

<Callout type="info">**As of v1.0.0-rc1**, Hyprland is configured in **Lua** (`hyprland.lua` and `hyprland/*.lua` modules), not the old `hyprland.conf`.</Callout>

Monitors default to their highest refresh rate (the `highrr` mode).
