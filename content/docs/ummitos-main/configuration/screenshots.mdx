# Screenshots

As of **v1.0.0-rc1**, screenshots are handled by the [Quickshell](/docs/ummitos-main/configuration/quickshell) shell (the old Hyprshot is gone). Captures are copied to the clipboard and saved to disk.

## Keybindings

| Keybinding | Mode |
|------------|------|
| `Print` | Full screen |
| `Shift + Print` | Region |
| `Super + Print` or `Super + Shift + W` | Active window |

`Print` takes the full screen at once, with no selection overlay. Notices stay on screen until the picture is taken, so they appear in it, and the notification panel stays open for the shot.

## Screenshot directory

The save location comes from the `HYPRSHOT_DIR` variable in `~/.config/hypr/hyprland/env.lua` (default: `~/Pictures`). Edit it to change where screenshots are stored, for example:

```lua
env = HYPRSHOT_DIR, /home/username/Pictures/Screenshots
```

<Callout type="info">Use an absolute path (full path), not a relative one.</Callout>

You have to log out and back in before the new path takes effect.
