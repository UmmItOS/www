# Desktop Shell (Quickshell)

As of **v1.0.0-rc1**, UmmItOS ships a custom [Quickshell](https://quickshell.org/) desktop shell written in QML. It replaces the old Waybar, Rofi, Swaync, Wlogout, Swww, Hyprlock and Hyprshot stack with a single integrated shell.

## Features

Everything below is drawn by the Quickshell shell:

- **Bar**: top panel with workspaces, status, and system info
- **Notifications**, with a history panel grouped by app
- **App launcher**: `Super + Return`
- **Clipboard manager**: `Alt + V`
- **Wallpaper picker**: `Alt + W`
- **Dashboard** and **session menu** (`Super + X`)
- **Volume / brightness OSD**
- **Flyouts** for Wi-Fi, Bluetooth, audio, and a user-selectable **accent colour**
- **Alt+Tab switcher** and a hot-corner **overview**
- **Keybind cheat sheet**: `Super + /`
- **Screenshot tool**: region, window, or full screen
- **Screen recording dialog**: `Super + Shift + R`
- **Lecture pen**: draw and zoom over a frozen screen (`Super + D`)
- **QR scanner**: opens links, joins Wi-Fi codes, copies text (`Super + Shift + Q`)
- **Lock screen**: `Super + L`
- **Settings panel**: the gear beside the power button. Its pages are Packages, Update (shows whether the shell is linked to a clone, with a Pull button; see [Staying Updated](/docs/ummitos-main/Updating)), Language (English, 廣東話, 台灣華語), recording options, recordings, and About
- **Desktop weather widget**, copy notices, and a charging ripple

## Accent colour

You can pick the shell's accent colour from its flyout.

## Languages

**Settings → Language** offers English, 廣東話 (written Cantonese), and 台灣華語 (Taiwanese Mandarin). Everything the shell draws is translated — the bar, notifications, lock screen, cheat sheet, QR scanner, weather, and dates. The choice switches live and is saved. For Traditional Chinese, `noto-fonts-cjk` is installed.

## Wallpaper

Pick the folder that random wallpapers are drawn from: right-click the bar's wallpaper button, or use **Shuffle from here** inside a folder in the picker (`Alt + W`). A small dot on the button means the shuffle is limited to one folder.

## Notifications

- If a window on a workspace you can't see asks for attention, you get a notice with a **Go there** button. This covers every link that opens your browser on another workspace.
- If a shortcut's program is missing, a notice names it and offers **Open Packages**.
