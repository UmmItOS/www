# Common Software Keybindings

These keybindings provide quick access to applications, the [Quickshell](/docs/ummitos-main/configuration/quickshell) shell, and utilities integrated into UmmItOS.

Keybindings are defined in the Lua Hyprland modules at `~/.config/hypr/hyprland/*.lua`.

## Applications

| Keybinding | Application | Description |
|------------|-------------|-------------|
| `Super + T` | Terminal (Kitty) | Open terminal emulator |
| `Super + E` | File Manager (Yazi) | Open file manager in terminal |
| `Super + Shift + Return` | Upgrade UmmItOS | Run the UmmItOS update script |

## Shell (Quickshell)

| Keybinding | Function | Description |
|------------|----------|-------------|
| `Super + Return` | App Launcher | Open the application launcher |
| `Super + X` | Session Menu | Open the power / session menu |
| `Super + /` | Cheat Sheet | Show the keybind cheat sheet |
| `Super + D` | Lecture Pen | Draw and zoom over a frozen screen |
| `Super + L` | Lock Screen | Lock the session |
| `Alt + V` | Clipboard | Open the clipboard manager |
| `Alt + W` | Wallpaper Picker | Open the wallpaper picker |
| `Alt + Tab` | Switcher | Switch between windows |
| `Alt + Shift + Tab` | Switcher (reverse) | Switch between windows in reverse |

## Utilities

| Keybinding | Tool | Description |
|------------|------|-------------|
| `Alt + E` | Emoji Picker | Open Smile emoji selector |
| `Alt + P` | Color Picker | Open Hyprpicker color picker |
| `Alt + O` | Magnifier | Launch Woomer screen magnifier |

## Screenshots & Recording

| Keybinding | Mode | Description |
|------------|------|-------------|
| `Print` | Full Screen | Capture entire screen |
| `Shift + Print` | Region | Select area to capture |
| `Super + Print` or `Super + Shift + W` | Window | Capture active window |
| `Super + Shift + R` | Recording | Start / stop screen recording |
| `Super + Shift + Q` | QR Scanner | Scan a QR code on screen |

<Callout type="info">Screenshots are copied to the clipboard and saved to `HYPRSHOT_DIR` (see [Screenshots](/docs/ummitos-main/configuration/screenshots)).</Callout>
