<Callout type="info">You can always bring up the in-shell **cheat sheet** with `Super + /`.</Callout>

## Quick reference

### Main modifier key

- **$mainMod = SUPER** (Windows key)

## Configuration files

Keybindings are defined in the Lua Hyprland modules:

- **Location**: `~/.config/hypr/hyprland/` (after installation)
- **Keybinds**: `~/.config/hypr/hyprland/*.lua`

<Callout type="info">**As of v1.0.0-rc1**, Hyprland is configured in **Lua** (`.lua`), not the old `.conf` files.</Callout>

## Applying the changes

Hyprland auto-reloads its configuration, so changes take effect immediately without a manual reload.
