## Overview

UmmItOS installs these packages by default. The full list lives in [`install/packages_main`](https://github.com/UmmItOS/UmmItOS/blob/main/install/packages_main); the tables here summarise it.

<Callout type="info">**As of v1.0.0-rc1**, a custom [Quickshell](https://quickshell.org/) desktop shell (QML) replaces the old Waybar + Rofi + Swaync + Wlogout + Swww + Hyprlock + Hyprshot stack. It now provides the bar, notifications, launcher, lock screen, wallpaper picker, screenshots and more. See [Desktop Shell](/docs/ummitos-main/configuration/quickshell).</Callout>
