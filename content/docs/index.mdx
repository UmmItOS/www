UmmItOS is an Arch Linux distribution built around the Hyprland window manager. These docs cover how to install it, configure it, and what it ships.

## What you'll find here

- **Installation**: prerequisites, the automated and manual methods, and post-install setup.
- **Configuration**: keybindings, screenshots, and the system-info display.
- **Packages**: the default packages UmmItOS installs.

<Callout type="info">These docs are still in progress. Contributions and feedback are welcome.</Callout>
