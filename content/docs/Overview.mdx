UmmItOS is a GNU/Linux distribution based on Arch Linux and Hyprland, with a custom [Quickshell](https://quickshell.org/) desktop shell plus its config and dotfiles.

### Current Status

- **Latest Release**: **v1.0.0-rc2**. The shell now speaks Cantonese and Taiwanese Mandarin, Settings can update the system and install missing packages, and the code has been through a full security review.
- **Available**: Configuration files and installer (`setup.sh` / `install-menu.sh`)
- **Bugs**: This is a release candidate, so bugs are expected. If you encounter any issues, please report them to the [GitHub repository](https://github.com/UmmItOS/UmmItOS/issues)
