## Overview

UmmItOS provides two ways to install: the quick setup script and manual installation.

- **Quick Installation**: Use the automated setup script (Recommended)
- **Manual Installation**: Clone the repository and run the installer yourself (for advanced users who want to install only certain parts)

<Callout type="warn">Do not run `install.sh` directly via `curl`. It sources files from `./install/` using relative paths, so it only works from a cloned repository. Use `setup.sh` (below) or clone the repo first.</Callout>

## Quick Installation

The setup script installs `git` and `paru` if they are missing, clones the repository with submodules, then runs the installer:

```shell
bash <(curl -fsSL https://raw.githubusercontent.com/UmmItOS/UmmItOS/HEAD/setup.sh)
```

<Callout type="info">The default branch was renamed `main` → `master`. `HEAD` always follows the current default branch, so the command above keeps working.</Callout>

### Installation Process

The installer performs the following steps. **Each step is optional and can be skipped individually for a modular installation.**

1. **Packages**: Installs the required packages via `paru`.
2. **GPU Detection**: Detects and installs AMD GPU packages (`vulkan-radeon`, `mesa`, `xf86-video-amdgpu`, lib32 drivers) when an AMD card is present.
3. **Laptop Detection**: Installs `brightnessctl` when a battery is detected.
4. **oh-my-zsh**: Sets up the Zsh framework.
5. **Configuration Copy**: Copies configurations to `~/.config` (prompts before overwriting existing files).
6. **Display Manager**: Replaces GDM with `greetd` running the UmmItOS Quickshell login screen. GDM stays installed but disabled.
7. **Reboot**: Reboot into your new setup.

<Callout type="info">UmmItOS supports **AMD GPUs only**; NVIDIA is not supported. Install on Arch Linux and do **not** run the installer as root.</Callout>

## Manual Installation

Clone the repository with submodules (the submodules include the default wallpapers):

```shell
git clone --recursive https://github.com/UmmItOS/UmmItOS.git
cd UmmItOS
```

Then run one of the installers:

```shell
./install-menu.sh   # Interactive TUI installer
./install.sh        # CLI installer
```

The installer prompts before overwriting existing configs, so you can pick which parts to apply.
