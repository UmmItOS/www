## QR scanner

Press `Super + Shift + Q`. The scanner freezes the screen and finds a code. A link opens in the browser, a Wi-Fi code joins the network, and plain text is copied.

## Other tools

- **SAO menu**: `Super + M`
- **Keybind cheat sheet**: `Super + /`
- **Battery usage**: `Super + B`
- **Picture converter**: `Super + I`
