# Screenshots

As of **v1.0.0-rc1**, screenshots are handled by the [Quickshell](/docs/configuration/quickshell) shell (the old Hyprshot is gone). Captures are copied to the clipboard and saved to disk.

## Keybindings

| Keybinding | Mode |
|------------|------|
| `Print` | Full screen |
| `Shift + Print` | Region |
| `Super + Print` or `Super + Shift + W` | Active window |

`Print` takes the full screen at once, with no selection overlay. Notices stay on screen until the picture is taken, so they appear in it, and the notification panel stays open for the shot.

## Screenshot directory

Open **Settings → Screenshots**, type a folder in **Save to**, then press Enter. It takes effect at once, and an empty field goes back to the default. The choice is saved in `~/.config/ummitos/screenshot.conf`. The same page has an **Open gallery** button (`Super + F`).

<Callout type="info">Use a full path like `~/Pictures`, not a relative one. The field shows a warning if the path is not full.</Callout>

The default is the `HYPRSHOT_DIR` variable in `~/.config/hypr/hyprland/env.lua`, which the installer sets to `~/Pictures`. If it is not set, screenshots go to `~/Pictures/Screenshots`. After editing `env.lua`, log out and back in.

## Gallery

`Super + F` shows every picture in that folder, newest first. Type to search the text inside the pictures (read with tesseract). Enter or a click copies the picture to the clipboard again.
