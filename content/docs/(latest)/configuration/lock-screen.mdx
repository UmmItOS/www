# Lock screen

import { Video } from '@/components/video';

Press `Super + L` to lock, or open the session menu with `Super + X`.

The lock screen shows the weather card at the top left. While something plays, the now-playing card sits at the foot of the screen with its controls, and a music spectrum, coloured from the accent, plays behind the clock. Reduce motion hides the spectrum. A wrong password twice raises an intruder warning.
