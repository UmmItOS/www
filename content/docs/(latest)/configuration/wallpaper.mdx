# Desktop and wallpaper

import { Video } from '@/components/video';

## Wallpaper

There are two pickers: the `Alt + W` carousel for the keyboard, and the wallpaper drawer for the mouse.

### `Alt + W` carousel

Press `Alt + W`. The arrow keys move through the pictures and preview each one live on the desktop. **Shuffle from here** picks one at random within the folder, and Enter keeps the one you're on.

### Wallpaper drawer

Choose **Wallpaper…** in the desktop right-click menu. A drawer opens on the right edge, with folder chips, named thumbnails, a check badge on the current picture, and a Shuffle button per folder. The desktop stays in view so you can preview a picture by hovering it.

Pick the folder that random wallpapers are drawn from: right-click the bar's wallpaper button, or use **Shuffle from here** inside a folder in the carousel. A small dot on the button means the shuffle is limited to one folder.

## Desktop menu

Right-click the empty desktop for Displays…, Wallpaper…, Settings, and switches for the weather card, now playing, the "Activate Linux" joke, and the FPS counter. The weather and now-playing cards sit on the desktop; the FPS counter is off by default.
