# Notifications and alerts

import { Video } from '@/components/video';

## Notifications

A history panel keeps notices grouped by app.

<Video
  mp4="/ummitos-notifications.mp4"
  webm="/ummitos-notifications.webm"
  poster="/ummitos-notifications-poster.jpg"
  caption="A window asking for attention on another workspace turns that workspace red, and Go there takes you to it. A shortcut whose program is missing says which one, and Open Packages shows what's missing in Settings."
/>

- If a window on a workspace you can't see asks for attention, you get a notice with a **Go there** button. This covers every link that opens your browser on another workspace.
- If a shortcut's program is missing, a notice names it and offers **Open Packages**.

## Heavy process warning

<Video
  mp4="/ummitos-heavy-warning.mp4"
  webm="/ummitos-heavy-warning.webm"
  poster="/ummitos-heavy-warning-poster.jpg"
  caption="After 12 seconds of heavy CPU or GPU, the bar names the process beside the latest file change, and clears it once the load drops."
/>

When one process uses more than half the CPU, or 80% of the GPU, for about 12 seconds, the bar shows its name and load beside the file-change label, for example "⚠ ffmpeg CPU 75%". The warning never stops the process. GPU use is shown only for your own processes.

To turn the warning off, open Settings, go to the **Misc** page, and switch off **Warn about heavy processes**.
