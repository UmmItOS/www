# Notifications and alerts

## Notifications

A history panel keeps notices grouped by app.

- If a window on a workspace you can't see asks for attention, you get a notice with a **Go there** button. This covers every link that opens your browser on another workspace.
- If a shortcut's program is missing, a notice names it and offers **Open Packages**.

## Heavy process warning

When one process keeps more than half the CPU, or 80% of the GPU, for about 12 seconds, the bar shows a warning with its name, for example "⚠ ffmpeg CPU 75%", beside the file-change label. It only warns and never kills anything. Only your own processes show GPU use. Turn it off in **Settings → Misc → Warn about heavy processes**.
