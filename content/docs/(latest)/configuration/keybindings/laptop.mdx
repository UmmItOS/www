# Laptop Keybindings

Keys for laptop hardware: brightness, volume, and media playback.

Usually these keys only available on laptop users. but you also can check it out! to use is just press the key you can see on the laptop keybaord, a little icon you can see on the key.

These keybindings are configured in the laptop section of the Lua Hyprland modules:

**Location**: `~/.config/hypr/hyprland/*.lua`

## Brightness Control

| Keybinding | Action | Description |
|------------|---------|-------------|
| `Brightness Up` | Increase Brightness | Increase screen brightness by 1% |
| `Brightness Down` | Decrease Brightness | Decrease screen brightness by 1% |

## Volume Control

| Keybinding | Action | Description |
|------------|---------|-------------|
| `Volume Up` | Increase Volume | Increase audio volume by 1% |
| `Volume Down` | Decrease Volume | Decrease audio volume by 1% |
| `Mute` | Toggle Mute | Mute/unmute audio output |

## Media Control

| Keybinding | Action | Description |
|------------|---------|-------------|
| `Play/Pause` | Toggle Playback | Play or pause current media |
| `Previous Track` | Previous | Skip to previous track |
| `Next Track` | Next | Skip to next track |

## Required Packages

For these keybindings to work properly, ensure these packages are installed:

| Package | Purpose | Install Command |
|---------|---------|----------------|
| `brightnessctl` | Brightness control | `paru -S brightnessctl` |

<Callout type="info">The installer installs `brightnessctl` automatically when a battery is detected. Volume and media keys are handled by WirePlumber (`wpctl`) / `playerctl`.</Callout>

## Customization

To modify laptop-specific keybindings:

1. Edit the configuration file.
2. Adjust the increment values (for example, change `1%` to `5%` for faster steps).
3. Add your own laptop shortcuts.
4. Save; Hyprland reloads the config on its own.

### Example Custom Configuration

```lua
-- In ~/.config/hypr/hyprland/media-keys.lua, change the existing lines.
-- bind() is defined at the top of that file and adds the cheat sheet entry.

-- Brightness in 5% steps
bind("XF86MonBrightnessUp", "brightnessctl set +5% && qs -c ummitos ipc call osd brightness", "Increase screen brightness")
bind("XF86MonBrightnessDown", "brightnessctl set 5%- && qs -c ummitos ipc call osd brightness", "Decrease screen brightness")

-- Volume in 2% steps
bind("XF86AudioRaiseVolume", "wpctl set-volume @DEFAULT_AUDIO_SINK@ 2%+", "Increase volume", { repeating = true, locked = true })
bind("XF86AudioLowerVolume", "wpctl set-volume @DEFAULT_AUDIO_SINK@ 2%-", "Decrease volume", { repeating = true, locked = true })
```
