## Before you start

Check the [Prerequisites](/docs/Prerequisites): Arch Linux, a normal user (not root), and an AMD GPU.

## Install

Clone the repository with its submodules (the submodules include the default wallpapers), then run the installer:

```shell
git clone --recursive https://github.com/UmmItOS/UmmItOS.git
cd UmmItOS
./install-menu.sh
```

`install-menu.sh` is the only installer. It opens a checklist in the terminal: tick the steps you want and they run one after another.

1. **Main packages**: installs the UmmItOS packages with `paru`, then enables Bluetooth and NetworkManager.
2. **GPU packages**: installs the AMD GPU packages when an AMD card is present.
3. **Laptop packages**: installs laptop tools when a battery is detected.
4. **oh-my-zsh**: sets up the Zsh framework.
5. **Dotfiles**: copies the configs into `~/.config`.
6. **Login screen**: installs `greetd` with the UmmItOS login screen and, if you agree, makes it the login manager in place of GDM. GDM stays installed, so you can go back.

<Callout type="info">The repository also has `setup.sh`. It offers to install `git` and `paru` if they are missing, clones the repository with its submodules, then offers to run `install-menu.sh`.</Callout>

When the last step finishes, a results screen shows how each one went. **Reboot** to start the new desktop.
